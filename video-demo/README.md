# Morelord Marketplace video demo

This folder contains a reproducible, captioned product demo assembled from the real screenshots in `docs/assets`.

## Build

From the repository root:

```powershell
.\video-demo\build-demo.ps1
```

The script requires FFmpeg and produces `morelord-marketplace-demo.mp4` in this folder. It has no audio, so it is suitable for autoplaying embeds and can be paired with narration or music later.

## Story arc

1. Introduce Morelord Marketplace.
2. Show the global buy/sell experience.
3. Highlight deep catalog filters.
4. Introduce scene-based vendors.
5. Show cart and funding context.
6. Present Shop Manager and stock controls.
7. Close on optional GM approval and the product name.
