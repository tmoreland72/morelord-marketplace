# Morelord Marketplace 0.3.2

## Fixed

- Added the Morelord Core manifest URL to the required-module relationship.
- Foundry can now locate and offer to install Morelord Core automatically when Marketplace is installed and Core is missing.

## Installation

Install Marketplace using its manifest URL. Foundry will detect that Morelord Core is required and prompt to install the dependency when it is not already installed.
