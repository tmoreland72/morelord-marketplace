# Transfer verification

Run `node --test test/*.test.mjs` for permissions, quantities, containers, duplicate requests, inventory rollback, concurrent source changes, and chat failure handling.

In verified Dev1, run `node tools/verify-transfer-foundry.mjs` from Marketplace. This uses isolated Chuck (GM) and Graypes (player) browser sessions, Core's shared runner, and disposable actors/items/chat cards. Player fixture requests target the fresh isolated GM client to leave other GM sessions untouched; ordinary players use Core's active-GM routing. Checks cover tab order/keyboard focus, shared inventory rows, cart minus/plus, whole-stack Group transfers, unowned recipients, denied source ownership, repeated sockets, stale quantities, and chat links. The layout check covers 30% Buy/Sell carts, Source ellipsis, and persisted filter collapse. Core's check covers horizontal tables and long item links. Fixtures are removed afterward. Screenshots cover dark/light themes at 1280px, 520px, and 360px plus an actual chat receipt. Reports are in `test/in-game-reports/transfer*.json`.

For a manual check, open Marketplace as a player. Confirm tabs read Sell → Transfer → Buy → Wishlist. Sell shows five table columns; Transfer shows Item, Qty, and Actions with the same coin and sack icons. Add one and a full stack, edit quantities in the wider Shopping Cart, select another character or Group, and submit. Confirm source and target quantities, unchanged currency, and the chat card. In a narrow window, confirm the cart stacks below inventory without horizontal page overflow. Empty a container before transferring it.
